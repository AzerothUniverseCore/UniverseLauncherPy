IMPORTANT - A LIRE AVANT DE COMPILER LE LAUNCHER
=================================================

Ce dossier doit contenir le fichier "UnRAR.exe" AVANT de lancer PyInstaller.
Ce fichier n'est PAS fourni avec les sources du launcher : c'est un binaire
Windows officiel a telecharger vous-meme (gratuit, redistribuable librement
pour de l'extraction), pour rester propre niveau licence/distribution.

NOTE - pourquoi UnRAR.exe et pas 7za.exe : le launcher utilisait au depart
7-Zip (7za.exe) pour extraire les archives .rar des patchs. Il s'avere,
apres verification directe (et confirmation par l'auteur de 7-Zip lui-meme
sur le forum officiel), que le binaire autonome "7za.exe" du paquet
portable "7-Zip Extra" ne sait JAMAIS lire les .rar, quelle que soit sa
version : la lecture RAR de 7-Zip passe par un plugin non-libre fourni
UNIQUEMENT dans l'installateur complet (celui qui s'installe dans
Program Files), jamais dans la version console/portable. Ce n'est donc pas
contournable en changeant de version de 7-Zip - UnRAR.exe est le bon outil.

Etapes :

1. Allez sur https://www.win-rar.com/download.html (site officiel WinRAR)
2. Dans la section de telechargement, cherchez "UnRAR" (parfois listee a
   part de WinRAR lui-meme - c'est un tout petit executable ~250 Ko,
   gratuit et sans limite d'essai, contrairement a WinRAR complet)
   - Alternative si vous avez deja WinRAR installe sur votre machine :
     le fichier existe deja dans C:\Program Files\WinRAR\UnRAR.exe (ou
     Rar.exe), vous pouvez directement le copier de la.
3. Placez le fichier exactement ici : tools/UnRAR.exe (a cote de ce fichier
   texte)
4. Vous pouvez alors lancer le build PyInstaller (voir build/BUILD_INSTRUCTIONS.md)

Sans ce fichier, le launcher affichera une erreur "UnRAR.exe introuvable"
des qu'il essaiera d'extraire une archive .rar (patchs, locales, contenu
additionnel).
